用户隐私协议

生效日期：2026-10-28

一、引言

本隐私协议旨在向您说明 ReiVerb Sound Atorie（以下简称「本站」）如何收集、使用与保护您的个人信息。请您仔细阅读本协议，并在同意全部条款后使用本网站。若您不同意本协议任何内容，请立即停止使用本网站。

二、我们收集哪些信息

1. 您主动提供的信息

本站不设账号系统，也不提供注册、订阅、在线支付等功能。您只有在主动联系我们时才会提供个人信息，例如直接发送电子邮件，或通过页脚的合作咨询表单填写姓名、合作事项与合作内容。

关于合作咨询表单：该表单通过您本地的邮件客户端发送邮件，本站服务器不接收、不存储、不留存您提交的任何内容。相关信息仅存在于您与我们之间的往来邮件中。
关于项目需求问卷：本站「Submit Brief」入口会跳转至第三方平台飞书（Feishu）填写项目需求问卷。您在该问卷中提交的信息由飞书平台存储与处理，本站不直接控制其存储方式与期限，相关处理适用飞书运营方公布的隐私政策。

2. 本站不收集的信息

本站不使用网站统计或用户行为分析工具，不投放广告，不追踪您的浏览行为，也不会收集您的浏览历史。

3. 托管与第三方服务

  • 网站托管：本站托管于 GitHub Pages。作为托管服务提供方，GitHub 可能记录访问日志（例如 IP 地址、访问时间、请求的资源）。该部分数据处理适用 GitHub 隐私声明。
  • 网页字体：本站使用 Google Fonts 提供部分字体，您的浏览器会向 Google 的服务器发起请求，Google 可能因此获取您的 IP 地址与浏览器信息。相关处理适用 Google 隐私权政策。若您不希望产生该请求，可通过浏览器扩展或网络设置阻止第三方字体加载。
  • 静态资源 CDN：作品「Research & Writing」页面通过 cdnjs.cloudflare.com（Cloudflare）与 cdn.jsdelivr.net（jsDelivr）加载 GSAP、ScrollTrigger、marked 等前端脚本。您的浏览器会向这两个域名发起请求，其服务方可能获取您的 IP 地址、浏览器信息与所请求的资源。相关处理适用 Cloudflare 隐私政策 与 jsDelivr 隐私政策。
  • 外部链接：本站页脚包含指向 GitHub、哔哩哔哩、小黑盒、微信等第三方平台的链接；「Submit Brief」入口会跳转至飞书（Feishu）填写项目需求问卷。点击后您将离开本站，其信息处理行为适用相应平台的隐私政策，本站无法控制亦不承担责任。

4. 第三方嵌入内容

本站部分页面可能嵌入第三方视频播放器（例如 YouTube）。若相关内容被加载，该第三方可能设置 Cookie 或收集您的访问信息，此类行为适用对应第三方的隐私政策。

三、信息使用

1. 使用目的

我们仅将您主动提供的信息用于：

  • 回复您的咨询、创作邀约或合作洽谈；
  • 就您提出的需求与您保持必要沟通；
  • 履行法律法规要求的义务。

我们不会将您的信息用于发送推广邮件或营销信息。

2. 信息共享与披露

我们承诺不会将您的个人信息出售、交易或租借给任何第三方，除非事先获得您的明确同意，或根据法律法规、司法或行政机关的强制要求。

四、信息保护

1. 传输安全

本站通过 HTTPS（安全套接层协议）加密传输，您与本站之间的通信内容不会被第三方窃听。该加密能力由托管服务方 GitHub Pages 提供。

2. 存储与保留

由于本站不存储您通过表单提交的内容，相关信息仅保存在我们用于接收与回复邮件的电子邮箱中。我们仅在处理您的咨询与合作所必需的期限内保留这些邮件，超出必要期限后予以删除。

3. 访问限制

仅本工作室的邮件接收者本人可访问上述信息。我们采取合理措施，防止您的信息遭到未经授权的访问、使用或泄露。

五、Cookie 与本地存储

本站不使用 Cookie，也不使用浏览器本地存储（localStorage / sessionStorage）记录您的任何信息。

第三方服务（例如 Google Fonts，或未来可能嵌入的视频播放器）可能在其自身域名下设置 Cookie，此类 Cookie 不在本站控制范围内，您可通过浏览器设置进行管理或清除。

六、未成年人隐私保护

我们非常重视对未成年人个人信息的保护。若您是未满 18 周岁的未成年人，请在法定监护人的指导下阅读本协议并使用本网站，并请勿在未经监护人同意的情况下向我们提供个人信息。

七、免责条款

1. 第三方链接

本网站可能包含指向第三方网站的链接。对于您在访问这些链接时可能遇到的个人信息收集和使用，我们无法控制亦不承担责任。请在离开本站后，自行阅读所访问网站的隐私政策。

2. 强制性法律要求

在法律法规要求的情况下，我们可能会披露您的个人信息。同时，我们保留在合理范围内使用、披露或保留相关信息的权利，以保护我们的合法权益、执行用户协议或应对法律诉讼。

八、协议更新与通知

我们保留随时更新本隐私协议的权利。更新后的协议将在本网站上公布，并同步更新本页顶部的生效日期。对于重大变更，我们将通过网站公告等方式通知。建议您定期查阅以了解最新的隐私政策。

九、适用法律与争议解决

本隐私协议的解释、适用与争议解决均适用中华人民共和国的法律。因本协议引起的或与本协议有关的争议，应通过友好协商解决；协商不成的，应提交至有管辖权的人民法院解决。
