## Design tokens

| 用途 | Token | 值 |
|------|-------|-----|
| 按钮底（主操作） | `--btn` / `--accent` | `#d0ff71` 青柠，按钮文字用墨色 `#010205` |
| 按钮 hover | `--btn-hover` / `--accent-hover` | `#e2ff9c` |
| 文字强调（斜体、链接、标签、指示线） | `--olive` | `#b0b748` 橄榄褐 |
| 次级点缀（圆点） | `--wine` | `#4e0115` |

规则：**青柠只用于块状按钮底，橄榄只用于文字与指示线**，两者不互换。
