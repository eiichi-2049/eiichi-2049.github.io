🎵 服务专长区块实现

✨ 在 #work 和 #about 之间新增深色区块

一个交互式服务列表，展示工作室的4大核心专长。 采用暗黑风格（背景：--ink，文字：--paper）与 智能 hover 交互（选中行放大变亮，其他行变暗）。 手机端自动禁用 hover，改为统一显示。

📋 结构概览

HTML 结构

<section id="services"> <div class="wrap"> <div class="sec-head"> <div class="eyebrow"> <i></i><i></i> <span>Our Expertise</span> </div> </div> <ul class="service-list"> <li class="service-row"> <div class="service-content"> <span class="service-number">01</span> <h3 class="service-title">原创配乐 · Composing</h3> <div class="service-thumb"> <img src="v2-bento/waveform.svg" /> </div> </div> </li> ... </ul> </div> </section>

🎨 核心特性

深色设计系统

背景 var(--ink)，文字 var(--paper)。 eyebrow 的两个点自动适配为白色 + 灰色， 确保在深色背景下的可读性。

智能 Hover 交互

用 CSS :has() 选择器实现兄弟元素联动。 Hover 时，选中行放大（1.2rem → 1.8rem） 变亮（opacity: 0.4 → 1）， 其余行变暗（opacity: 0.3）。所有变化过渡 0.3s。

缩略图淡入

Hover 时，右侧缩略图淡入（opacity: 0 → 1）。 使用 SVG（v2-bento 目录），filter: invert(1) 反色显示，适配深色背景。

完全响应式

编号/标题/缩略图大小均用 clamp() 随屏宽自适应。 手机端（≤760px）禁用所有 hover，改为统一显示。

无需 JS

完全用 CSS :has() 和 transition 实现。 没有 JavaScript，性能最优，兼容性好（现代浏览器）。

易于定制

服务行数、文案、SVG 图片都可直接修改 HTML。 颜色、间距、字号全在 CSS 变量或 clamp() 中管理。

💻 CSS 核心代码

/* 列表容器 */ .service-list { list-style: none; display: flex; flex-direction: column; gap: 32px; } /* 每行容器 */ .service-row { position: relative; border-bottom: 1px solid rgba(249, 249, 249, 0.15); padding-bottom: 24px; } /* 标题默认状态：较小、较暗 */ .service-title { font-size: clamp(1.2rem, 2vw, 1.8rem); opacity: 0.4; transition: all 0.3s ease; } /* 🔥 核心交互：hover 时放大变亮，其余变暗 */ .service-list:has(.service-row:hover) .service-row:not(:hover) .service-title { opacity: 0.3; font-size: clamp(1rem, 1.8vw, 1.5rem); } .service-list:has(.service-row:hover) .service-row:hover .service-title { opacity: 1; font-size: clamp(1.4rem, 2.2vw, 2rem); } /* 缩略图淡入 */ .service-list:has(.service-row:hover) .service-row:hover .service-thumb { opacity: 1; } /* 手机端：禁用 hover，统一显示 */ @media(max-width: 760px) { .service-title { opacity: 1 !important; font-size: 1.4rem !important; } .service-thumb { display: none; } }

🧪 验证清单

  • 打开 本地预览 或查看完整页面
  • 在桌面宽度（≥1200px）下，鼠标 hover 任意一行
  • 验证：该行标题放大（1.8rem → 2rem）、变亮（0.4 → 1）
  • 验证：其他行变暗（0.4 → 0.3）、文字缩小（1.8rem → 1.5rem）
  • 验证：右侧缩略图淡入（SVG 反色显示）
  • 验证：所有变化用 0.3s ease 过渡，流畅无卡顿
  • 缩小窗口到手机宽度（≤760px）
  • 验证：所有行恢复统一大小、opacity 1、不响应 hover
  • 验证：缩略图隐藏，编号和标题纵向堆叠
  • 验证：深色背景（--ink）和浅色文字（--paper）正常显示

📝 可定制项

轻松修改这些内容：

  • 服务项数：在 HTML 中复制/删除 <li class="service-row">
  • 服务名称和编号：直接改 .service-number 和 .service-title
  • 缩略图：改 <img src="v2-bento/...">，复用其他 SVG 或上传新图
  • 颜色：改 CSS 中的 var(--ink) / var(--paper) 或直接改值
  • 间距和字号：调整 clamp() 中的数值
  • 动画时间：改 transition: all 0.3s ease 中的 0.3s
  • Hover 时的变化幅度：改 opacity 值（0.3/0.4/1）或 font-size 范围
